# 🕉️ Pooja Bhakti Bhajan

**Pooja Bhakti Bhajan** (PBB) is a premier static devotional web portal for Sanatan Dharma — featuring Aartis, Chalisas, Mantras, a Live Hindu Panchang, 108x Digital Jaap Mala counter, and WhatsApp Blessing Generator.

🌐 **Live Site:** [poojabhaktibhajan.com](https://poojabhaktibhajan.com)

---

## ✨ Features

- 🎵 **Audio Player** — Devotional Aartis, Chalisas, and Bhajans with 108x repeat mode
- 📅 **Live Hindu Panchang** — Real astronomical Tithi, Nakshatra, Rahu Kaal, and Shubh Muhurat
- 📿 **108x Digital Jaap Mala** — Track your daily chanting with streak counter
- 📖 **Daily Bhagavad Gita Shloka** — Rotating daily shloka with meaning
- 🌸 **WhatsApp Blessing Generator** — Send personalized divine greetings
- 🌙 **Dark / Light Theme** — Sacred devotional color palettes
- 📱 **Fully Responsive** — Mobile-first design

---

## 🛠️ Tech Stack

- **HTML5 + CSS3 + Vanilla JavaScript** — Zero dependencies, zero frameworks
- **Web Audio API** — Synthesized temple bell and Om drone sounds
- **LocalStorage** — Persist Jaap Mala count and theme preference
- **Deployed on Vercel** — Global CDN, automatic HTTPS

---

## 🚀 Deployment

This is a pure static site deployed on [Vercel](https://vercel.com).

Every push to the `main` branch triggers an automatic deployment.

---

## 🔒 Security

Security headers enforced via `vercel.json`:
- Content-Security-Policy
- Strict-Transport-Security (HSTS)
- X-Frame-Options
- X-Content-Type-Options
- Referrer-Policy
- Permissions-Policy
